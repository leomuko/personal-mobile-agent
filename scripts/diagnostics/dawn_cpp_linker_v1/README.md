# Linker selection investigation v1

This is a preparation-only namespace. There is no native executor or `--run`
command. `prepare.py` hashes existing inputs, checks preserved results, scans no
program behavior and writes one exclusive, deterministic seven-query proposal.
`plan.py` constructs argv/environment/the unchanged compiler-only sandbox.
`policy.py` tests a separately proposed output contract without editing old policy.

One lookup is diagnostic only: the exact retained bare `ld` response remains
unqualified. Six explicit `--ld-path=<pinned ld>` `-###` plans must show that same
literal absolute linker and pass every existing closed driver-plan check. Unknown
defaults, warnings, alternate suppliers or relative identities still reject. No
linker exec rule, compilation, include-search continuation or C++ matrix is added.

Preparation can run with the pinned Python using `-I -S -B` and
`--output planning/fixtures/dawn-cpp-linker-v1/probe-freeze-r1.json` (absolute path).
No prior evidence is overwritten. Input hashing and full six-tree comparisons are
data-only, not native queries. Snapshot scanning is bounded to 256 MiB/2 MiB
blocks/16 offsets per fixed needle, with an explicit omitted-occurrences flag.
This is a bounded sample, not a complete occurrence inventory. String occurrences do not prove parser support
or behavior. The future probe directory must remain absent.

Review this contract before implementing a native owner/runner. That future
implementation needs its own regressions, actual read-only admission proof and
reviewed exact execution freeze, then separate user authorization. A proposal
freeze, QA PASS or diagnostic lookup never authorizes dispatch. Existing 300s
decision/15s cleanup/30s per-query ceilings and all output/RSS bounds are retained.
The 1 GiB small-slice floor is separate from the unchanged 18 GiB analysis floor.
P2 remains incomplete; semantic search is disabled; S24 tests remain deferred.
